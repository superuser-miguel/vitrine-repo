Vitrine — signed Flatpak repo

Automatic updates for Vitrine, the catalog-aware image browser for GNOME.

flatpak install --user https://superuser-miguel.github.io/vitrine-repo/vitrine.flatpakref
flatpak run io.github.superuser_miguel.Vitrine

Updates then arrive with flatpak update. The repo is signed with the project's GPG key, which the .flatpakref carries.

Installed an earlier version from a .flatpak bundle? Uninstall it once, then install from the link above to start receiving updates.
